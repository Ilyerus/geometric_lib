# Описание файлов
## rectangle.py
### area(a, b)
Возвращает значение площади прямоугольника по формуле $S = a b $
**Сигнатура функции следующая:**
```
    Параметры:
        a (float) - первая сторона
        b (float) - вторая сторона
    Возвращаемое значение:
        a * b (float) - площадь
```
**Примеры использования**
```python
input: area(2,4 )
output: 8
input: area(1.19, 13.23)
output: 15.7437
```
### perimeter(a, b)
Возвращает значение периметра прямоугольника по формуле $P = 2 (a + b)$
**Сигнатура функции следующая:**
```
    Параметры:
        a (float) - первая сторона
        b (float) - вторая сторона
    Возвращаемое значение:
        (a + b) * 2 (float) - периметр
```
**Пример использования**
```python
input: perimeter(3, 6)
output: 18
input: perimeter(1.9, 5.3)
output: 14.399999999999999
```

## circle.py
Для работы функций в файле необходимо импортировать стандартную библиотеку math:
`import math`

### Функции
#### area(r)
Возвращает значение площади круга по формуле $S = \pi r^2 $
**Сигнатура функции следующая:**
```
    Параметры:
        r (float) - радиус
    Возвращаемое значение:
        math.pi * r * r (float) - площадь
```
**Примеры использования**
```python
input: area(1)
output: 3.141592653589793
input: area(4)
output: 50.26548245743669
```
#### perimeter(r)
Возвращает значение длины окружности по формуле $C = 2 \pi r $
**Сигнатура функции следующая:**
```
    Параметры:
        r (float) - радиус
    Возвращаемое значение:
        2 * math.pi * r (float) - периметр
```
**Пример использования**
```python
input: perimeter(13)
output: 81.68140899333463
input: perimeter(2.5)
output: 15.707963267948966
```

##  triangle.py
### Функции
#### area(a, h)
Возвращает значение площади треугольника по формуле $S = \frac{ah}{2} $
**Сигнатура функции следующая:**
```
    Параметры:
        a (float) - сторона
        h (float) - высота
    Возвращаемое значение:
        a * h / 2 (float) - площадь
```
**Примеры использования**
```python
input: area(3, 4)
output: 6
input: area(1.73, 1.65)
output: 1.42725
```
#### perimeter(a, b, c)
Возвращает значение периметра треугольника по формуле $P = a+b+c $.
**Сигнатура функции следующая:**
```
Параметры:
        a (float) - первая сторона
        b (float) - вторая сторона
        c (float) - третья сторона
    Возвращаемое значение:
        a + b + c (float) - периметр
```
**Пример использования**
```python
input: perimeter(2, 2, 3)
output: 7
input: perimeter(1.2, 2.7, 3.5)
output: 7.4
```
